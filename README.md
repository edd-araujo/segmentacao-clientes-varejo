# Segmentação de Clientes de Varejo

Projeto A3 da matéria de Inteligência Artificial da UNIFACS - 2026.1.

---

# 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver uma aplicação capaz de segmentar clientes de uma empresa de varejo (supermercado) utilizando algoritmos de aprendizado de máquina não supervisionado.

A segmentação permitirá identificar padrões de comportamento dos clientes com base em características presentes no dataset, possibilitando análises estratégicas e campanhas de marketing personalizadas.

---

# 🎯 Objetivos

- Realizar análise exploratória dos dados (EDA)
- Aplicar técnicas de pré-processamento
- Implementar algoritmos de clustering
- Visualizar os segmentos encontrados
- Comparar diferentes algoritmos de Machine Learning
- Analisar métricas de desempenho
- Interpretar os grupos de clientes gerados

---

# 🧠 Algoritmos Utilizados

- K-Means Clustering
- DBSCAN
